## How I work

**Business question first.** Before any code, we agree what this needs to do, in numbers.

**Risky part first.** I prototype the hardest piece early, so we find out cheaply whether the idea survives real data.

**Reliable from day one.** Testing, monitoring and security go in at the start instead of being bolted on at the end.

**No surprises.** You'll always know where things stand, because I overcommunicate on purpose.
